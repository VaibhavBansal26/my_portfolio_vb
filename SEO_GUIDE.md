## Step-by-Step Ranking Action Plan

### Week 1 — Technical Foundation (Do these first)
1. Deploy to Vercel at vaibhavbansal.in
2. Go to https://search.google.com/search-console
   - Add property → URL prefix → https://www.vaibhavbansal.in
   - Download the verification HTML file → put in /public/
   - OR copy meta tag code → paste into layout.tsx verification field
3. Submit sitemap: https://www.vaibhavbansal.in/sitemap.xml
4. Request indexing for each page manually in Search Console
5. Check rich results: https://search.google.com/test/rich-results
   - Paste your URL → should show Person schema ✓

### Week 2 — Backlinks (Most important ranking factor)
These tell Google your site is authoritative:

**Free, high-impact:**
- Post on LinkedIn: "I just launched my portfolio" → include link
  → Every LinkedIn connection who visits = a signal to Google
- Update GitHub profile README with portfolio link
- Update all GitHub repo descriptions to include portfolio link
- Post on Twitter/X with link
- Submit to HackerNews "Show HN: My AI Engineer portfolio"
  → Even 10 upvotes = major SEO boost

**Directory submissions (free):**
- https://wellfound.com (AngelList) — add portfolio URL to profile
- https://polywork.com — create profile
- https://dev.to — write one article, link to portfolio
- https://hashnode.com — same
- https://contra.com — freelancer profile
- https://toptal.com/portfolio (if accepted) — huge authority

**Medium articles (you already have them):**
- Edit each Medium article → add "Author: [Vaibhav Bansal](link)" with portfolio URL
- Write 1 new article: "Building Production RAG Pipelines with LangChain"
  → Target keyword: "LangChain RAG tutorial" → link back to portfolio

### Week 3 — Content (Sustain rankings)
Google rewards fresh content. Add to your blog/portfolio data file:
- New project every 2-3 months
- New blog post monthly
- Update "What I'm building now" card weekly
